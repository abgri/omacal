OmaCal Brian

OmaCal Brian is a personal macOS calendar application maintained by Brian Acklen. It is a customized fork of OmaCal, separate from the upstream application.

It connects directly to Google Calendar to display and synchronize calendars and events, manage event changes and invitations, and provide reminders. Calendar data is cached on the Mac for local use.

This build is intended for its owner’s personal use, not a public hosted calendar service.
